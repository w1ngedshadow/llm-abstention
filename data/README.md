# Данные бейзлайна

В папке лежат примеры VitaminC, использованные в первом эксперименте. Мы выбрали целые группы и сохранили исходные строки JSONL со всеми полями. Источник — Tal Schuster и соавторы, VitaminC. Выборка распространяется под той же лицензией CC BY-SA 3.0. [Версия датасета](https://huggingface.co/datasets/tals/vitaminc/tree/be6febb761b0b2807687e61e0b5282e459df2fa0) · [Лицензия](https://creativecommons.org/licenses/by-sa/3.0/)

| Файл | Примеры | Группы | Назначение |
|---|---:|---:|---|
| [baseline_dev.jsonl](baseline_dev.jsonl) | 657 | 200 | Подбор порога и температуры |
| [baseline_test.jsonl](baseline_test.jsonl) | 669 | 200 | Оценка на тексте и Markdown-таблицах |

Каждая строка содержит утверждение (`claim`), источник (`evidence`) и правильный ответ (`label`). Метки — `SUPPORTS`, `REFUTES` и `NOT ENOUGH INFO`. Поле `unique_id` связывает пример с предсказанием модели. Поле `case_id` объединяет связанные примеры. Правильность ответов проверяем по исходной разметке VitaminC.

Группы выбирали с seed 42 из официальных dev и test. Между выборками группы не пересекаются. В первом опыте порог выбирали на всём dev. Для температурной калибровки dev разделили на 100 групп для температуры и 100 для порога. На тесте одни и те же строки подавали в двух оформлениях с одинаковой инструкцией и меткой. Обучающая часть VitaminC в бейзлайне не использовалась.

Прочитать выборку из корня проекта можно командой Python `pd.read_json("data/baseline_dev.jsonl", lines=True, dtype=False)` после `import pandas as pd`. При полном запуске ноутбук получает официальные dev и test через Hugging Face и повторяет выборку. [Ноутбук](../results/baseline_vitaminc.ipynb) · [Предсказания](../results/qwen3b_baseline/)
